Best use of the data

Five worked uses of the open JUNO datasets, from download to scoring a period that is not in the record yet.

The JUNO datasets are open. These five worked uses go from downloading a file to scoring a period that is not in the record yet. Every file linked here is in the site repository; counts are computed from the files themselves (as of 20 November 2026).

1. Download the JUNO v3 corpus and pull out one society

JUNO_Unified_Dataset_v3_2026-10-19.csv: 41,914 rows, 42 societies, 1752 to 2026, one row per society, year and node. Columns: Society, Year, Node, Coherence, Capacity, Stress, Abstraction, Node_Value_v2, Source_File, Source_Note. What changed in v3 is in the changelog; the wider archive is on Datasets.

import pandas as pd
df = pd.read_csv("JUNO_Unified_Dataset_v3_2026-10-19.csv")
au = df[df.Society == "Australia"]
au.pivot_table(index="Year", columns="Node", values="Stress").tail()

In a spreadsheet, filter the Society column instead. Each row is one node in one year, so a full year is eight rows: Helm, Shield, Lore, Stewards, Craft, Hands, Archive, Flow.

2. Load one society into Advanced Analysis

  1. Download a single-society file, for example Australia_ENS_1875_2026_cleaned.csv (1,216 rows, 1875 to 2026, columns Society, Year, Node, Coherence, Capacity, Stress, Abstraction, Node Value, Bond Strength).
  2. Open CAMS Advanced Analysis and use Upload CSV. The file carries a Bond Strength column, which turns on the full 3D attractor view.
  3. Read the stress profiles and coupling between nodes over time, and look for the phase of the Holling cycle each period sits in: exploitation, conservation, release or reorganisation.

Advanced Analysis groups uploaded rows by Year and Node only. Upload one society at a time: a multi-society file such as the v3 corpus would be averaged across societies. Filter it first (use 1), or pick a society from the page’s built-in list.

3. Compare two societies

In the browser: CAMS Compare sets two societies side by side on one kernel with a year slider. In code, from the v3 corpus:

pair = df[df.Society.isin(["Australia", "Argentina"]) & df.Year.between(1950, 2026)]
pair.assign(SK=pair.Stress / pair.Capacity) \
    .groupby(["Society", "Node"]).SK.mean().unstack(0).round(2)

The ratio of Stress to Capacity per node shows where each system carries load it cannot absorb. Read it as stress levels and coupling, not as a score of merit: a score is a state, not a grade. Before reading anything into the network quantities, see the Temporal Inelasticity audit, which limits what bond-derived measures can carry.

4. Score a new period and set it against the record

  1. Score the eight nodes for one society and one year: by hand with the DIY Kit, or with the CAMS Scorer.
  2. Type the 32 integers into the JUNO Calculator to get Node Values, bond strengths and the system readouts, with every formula printed on the page. Definitions are on Canonical Definitions.
  3. Copy the CSV it produces and append it to the same society’s rows from use 1 to see whether your year continues the trajectory or breaks from it.

A new score is one reading by one scorer. The site’s own panels use ensembles of independent passes; treat a single score as a hypothesis to test against them.

5. Test the record blind

The Blind Analysis Challenge gives anonymised society files with years replaced by offsets, a protocol prompt for any capable model, and a sealed key. Run it before you look at the named data, so the result is yours and not a recognition of history you already know.
