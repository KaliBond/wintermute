CAMS-CAN DIY KIT
================

Contents:
- PROJECT_INSTRUCTIONS.txt   Paste into a Claude Project's "Project instructions"
                             field. Sets up scoring, calculation, ensemble rules
                             and entity mappings (nation/corporation/city).
- schema_template.csv        Blank Block 1 schema (score + calc output) for one
                             year, eight canonical node rows. Fill Society, Year
                             and C/K/S/A; Node Value and Bond Strength are
                             computed by the CALC job or the online calculator.
- envelope_schema_template.csv  Blank Block 2 schema for evidence-gated ensemble
                             runs (camnations5n): per-scorer spread, n_eff, NA_rate.

Full method, formulas and a live calculator: see the CAMS-CAN working paper
this kit accompanies. Framework by Kari McKern, Neural Nations —
neuralnations.org / github.com/KaliBond/wintermute. This kit is an independent
condensation for hands-on use, not an official Neural Nations release.
