# Do the blind-file controls work? Control validity report

Generated by `praxis/controls/test_controls.py`. Re-run the script; do not edit by hand.

Sample: 789 windows of 24 consecutive scored years, up to 30 per society, from 33 primary ensemble series in `data/v1.0_final_recompute/`. Random seed 20261114. All scores are model-generated, and windows from one society overlap, so treat the figures as descriptive. 4334 candidate windows were skipped because fewer than 12 of their 24 rows were distinct (a flat stretch cannot be meaningfully permuted). In the game, a flat window makes the permuted file nearly identical to the real one.

## The two controls are different experiments

| | Row permutation (`perm`) | Node-label shuffle (`shuf`) |
|---|---|---|
| What is changed | The order of the scored rows. The year column stays in sequence. | Which node name each column block carries. One relabelling per window, applied to every row. |
| Meant to destroy | Trajectory: sequence, trends, turning points, timing. | Node identity: which function (Helm, Shield, ...) is strong, weak or stressed. |
| Meant to keep | Every value, and which node it belongs to. | Every value, the order of years, and all label-free system metrics. |
| A false positive is | A confident story about how things changed over time. | A confident claim about a named node. |
| NOT a false positive | Naming the society from its levels. | Describing the trajectory of system-wide metrics. |

## 1. Temporal structure

Lag-1 autocorrelation of yearly mean viability within a window (1 = smooth, 0 = no memory).

| Arm | median | 5th to 95th percentile |
|---|---:|---:|
| real | 0.69 | 0.26 to 0.88 |
| perm | -0.04 | -0.32 to 0.27 |
| shuf | 0.69 | 0.26 to 0.88 |

- Row permutation removes the time structure: median 0.69 falls to -0.04.
- Node-label shuffle leaves it untouched: the largest change in any yearly mean viability is 3.6e-15.

## 2. Marginal content

- Row permutation keeps every node's set of values exactly: yes.
- Node-label shuffle keeps the pooled set of values exactly: yes.

## 3 and 4. Can the society still be identified?

A nearest-centroid rule names the society from window averages. Centroids exclude the window's own years. Chance is 3.0% (33 societies).

| Features | real | perm | shuf |
|---|---:|---:|---:|
| Node-labelled levels (mean C, K, S, A per named node) | 47.5% | 47.5% | 22.2% |
| Label-free levels (ignore row order and node names) | 33.7% | 33.7% | 33.7% |

- **Row permutation does not hide who the society is.** Identification from levels is unchanged (47.5% real, 47.5% permuted), because averages do not depend on row order. On a permuted file, a correct identification is not evidence of over-reading. Only trajectory claims are.
- **Node-label shuffle weakens node-labelled identification but does not remove it** (47.5% falls to 22.2%, still well above the 3.0% chance rate), because a society's overall level survives any relabelling. Label-free identification is unchanged (33.7%). On a shuffled file, a correct identification is not a false positive. Only claims about named nodes are.

## 5. Can a model tell it has been given a control?

A control is only blind if it cannot be spotted. AUC is the chance that one simple statistic ranks a real window above its control (0.5 = undetectable, 1.0 = always detectable).

| Control | Statistic | AUC |
|---|---|---:|
| Row permutation | lag-1 autocorrelation of yearly mean viability | 0.99 |
| Node-label shuffle | match between the window's node profile and the average profile of other societies | 0.84 |

- **Row permutation is easy to detect** (AUC 0.99). Real series are smooth; a permuted one jumps about. A capable model can notice, and may then hedge, which would make the control look cleaner than it is. With real calendar years shown, the mismatch is even plainer.
- **Node-label shuffle is also detectable** (AUC 0.84) from this statistic, because nodes have typical profiles across societies.

## What this means for the pilot

1. Score the two controls on different claim types. Row permutation tests trajectory claims. Node-label shuffle tests named-node claims. Neither tests identification.
2. Do not treat a correct society guess on a control as a failure. The information that supports it is still in the file.
3. Row permutation is not blind. Report detection separately: ask analysts, after they answer, whether the data looked scrambled.
4. The pilot arms now carry only label-free system columns, so the three files of a triplet have the same shape and no column is tied to a named node.

## Unresolved

- Whether to replace or supplement row permutation with a surrogate that keeps smoothness but breaks the real sequence (for example block permutation, time reversal, or phase-randomised surrogates). Each destroys something different, and the choice belongs in the pre-registration.
- Whether node-label shuffle should be restricted (for example, shuffling only within the slow group and within the fast group) to make it harder to spot, at the cost of destroying less.
- These tests use simple statistics. A language model may detect or miss things these do not. The real check is the pilot's own negative-control false-positive rate.
