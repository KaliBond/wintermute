# CAMS History

Named atlas, blind call, and primer for the JUNO panel.

Three screens:

- **Atlas** — societies with the names on. Eight nodes, node value, bond ring, and the year you are standing in.
- **Prophet** — the same instrument with the names covered. Call the break before the reveal.
- **Primer** — how to read it. V = C + K − S + ½A.

Node value is coherence plus capacity, minus stress, plus half of abstraction. A year is strained when the worst node is under 4, and severe when value passes through zero.

## Run it

```bash
cd cams-history
npm install
npm run dev
```

The dev server listens on port 8080.

Data lives in `public/data/panel.json` (named JUNO panel) and `public/data/cases.json` (blind rounds).
