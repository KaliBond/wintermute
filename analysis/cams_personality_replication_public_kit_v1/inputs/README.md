# CAMS public replication — source inputs (2026-11-07)

Public bundle of **genuine issued** participant/operator source inputs for repeating the CAMS lean personality portrait arms (A / B protocol / C).

Prepared so an independent group can:

1. Run **Arm A** (blind pocket writing from era-means tables; no web).
2. Understand the **Arm B** challenge shape, and have an operator mint a **new** blind set (the historical blind pockets here are spoiled).
3. Run **Arm C** (independent mood continuity; web allowed) against their own hashed Arm A outputs.

This zip does **not** contain HOLD answer keys, sealed analyst pockets, or closed-round scored returns.

## Quick start

1. Read `CONTAMINATION_AND_SPOILERS.md` and `HOLD_KEYS_WITHHELD.md`.
2. Open `arm_a_standard/README.md`, then `node_definitions.md` and `algebra_and_rules.md`.
3. Use `arm_a_standard/era_means.csv` (CORE), optionally `era_means_extension.csv`, then `era_means_denmark.csv` (LIMIT).
4. Return Arm A per `arm_a_standard/output_schema.md` and hash the file before any web research.
5. For Arm C, use `arm_c_mood/` with your hashed Arm A file (CSVs stay in `arm_a_standard/`).
6. For a **fresh** Arm B, see `arm_b_blind_historical/SPOILER_READ_FIRST.md` and mint new unlabeled pockets; do not treat `pockets_blind.jsonl` as a live secret.
