# PREREG (FROZEN): do node-relationship shifts in the canonical USA_ENS lead externally dated markers?

**Status: FROZEN 29 Oct 2026 (Sydney) on Kari McKern's approval of the drafted defaults ([pt273u]), before any drift series, upcrossing or marker-event comparison was computed. The sha256 of this file and the marker CSVs is in `FROZEN.txt`. Changes after freezing go in section 11 only.**
The earlier draft is kept as `PREREG_draft_v0.md` for audit. Node names follow JUNO v1.2 (Helm, Shield, Lore, Stewards, Craft, Hands, Archive, Flow).

## 1. Why this exists
The earlier test (`/workspace/analysis/usa_ensemble_vs_periods/`, H2) used 14 conventional transition dates. Kari agrees those dates are themselves coordination-stress signals, so H2 was confounded: the markers were partly defined by the thing the drift measure detects. This design replaces them with markers dated by outside procedures (a committee, an election count, a ratification), not by strain narratives. H2 results are neither revised nor reinterpreted here.

## 2. Question and hypothesis
**Question.** Do shifts in how the eight nodes relate to one another in the canonical annual USA_ENS precede externally dated markers more often than chance?
**H_E (primary).** Annual drift upcrossings of the state-based measure X^S fall in the lead window T−5..T−1 of NBER business-cycle peaks more often than expected under the circular-shift and random-date nulls, and more often than in the lag window T..T+4.
The test is about temporal order only. It makes no claim that node shifts cause the markers.

## 3. Data
- `/workspace/uploads/usa_ens_annual/USA_ENS_annual.csv`: 127 years (1900–2026) × 8 nodes. 2026 is dropped, leaving 1900–2025.
- md5 `1c9626e9481662df6c00974f720e0ec0` is for the box reconstruction of the upload. **The original file's checksum is unavailable.** Provenance caveat: the analysis rests on the box copy, and any difference from Kari's original is not detectable.
- Q = Abstraction × Coherence + Capacity − Stress. Annual tilt θ_t = Q_t − mean over the eight nodes. Node Value and Bond Strength are not used (as in the frozen machinery).
- Stepwise structure: 72 of 125 year-to-year changes are exactly zero. The series has 54 distinct states (a state is the vector of eight Q values; a new state starts when any of the eight differs from the previous year).
- **Threat to flag (rater anchoring).** The state boundaries (e.g. 1907, 1908, 1910) may sit at years a rater already associated with known events. If so, state changes can cluster at or just after markers by construction. The lead window excludes T itself, and F7 below tests for this pattern, but it cannot be removed by design. This is a limit on any lead claim from this file.

## 5. Drift measures
**Primary: X^S (state-based).** With states s_0, s_1, … in order, for any year t in state s_k with k ≥ 3: X^S_t = 1 − cos(θ(s_k), mean of θ over the previous min(5, k) distinct states). The value is carried forward across all years of the state. Rationale: the annual X of the frozen run mixes real shifts with repeats of the same state (X can be exactly 0 or a flat plateau), so lead timing inside a plateau is not information. X^S can upcross only in a year a new state begins, which is the only year new information exists. Minimum 3 previous states is a design choice (decided, section 10); it gives X^S support from 1910 and first upcrossing-capable year L = 1911.
**Secondary measures (reported beside the primary, never replacing it):**
- X^A: the frozen annual X (mean of previous 5 calendar years). Continuity with H2; stepwise artefacts acknowledged.
- X^C: X^S values taken once per state (at the state's first year), P90 over states only. An event is a state start year whose value is ≥ that threshold while the previous state's value was below it. Diagnostic and exploratory; no verdict attached.
Threshold: `np.percentile(X^S over its support 1910–2025 (all years, so long states weigh by duration), 90)`, the frozen call. Upcrossing: X_{t−1} < thr ≤ X_t.

## 6. Procedure (reuses frozen machinery from `/workspace/analysis/usa_ensemble_vs_periods/run.py`, PREREG sha256 `3603e474ada3652e2d665e8787ca9c4bb08ba3e38bd23a8614e69611c3aea2fe`)
6.1 **Eligibility.** Marker T is scored if L+6 ≤ T ≤ 2021 (L = first upcrossing-capable year). This is the frozen 1912–2021 window re-expressed so it adapts to X^S support. Currently [1917, 2021].
6.2 **Hits.** S_lead = number of scored markers with ≥ 1 upcrossing in T−5..T−1. S_lag likewise in T..T+4. A marker counts once per window.
6.3 **N1 circular shift.** Shift the upcrossing years circularly over L..2025, excluding shifts s with min(s, N−s) ≤ 2. Preserves event spacing and clustering. Null for S_lead and S_lag.
6.4 **N2 random dates.** Draw n distinct years uniformly from [L+6, 2021] with minimum spacing m = min(4, max(1, smallest gap in the observed scored set)), B = 10000, seed 20261029. p = share of null S_lead ≥ observed (with the frozen +1 convention).
6.5 **Multiplicity.** One confirmatory test (E1 primary, X^S), α = 0.05, no adjustment. The secondary family (E2, E3) uses the frozen `holm` over the two sets, using for each set the larger of its p_N1 and p_N2 (α = 0.05). A secondary set is called "supportive" if S_lead/n ≥ 0.60, S_lead > S_lag and it passes Holm; otherwise "not supportive". Secondary results never change the primary verdict. C1 is not in the family.
6.5a **Implementation details fixed before running.** One `numpy.random.default_rng(20261029)` is created at the start; draws occur in this order: E1 N2, E2 N2, E3 N2, C1 N2, then exploratory items in the order of section 9. N1 is the frozen `null_N1` applied to the X^S upcrossing series. N2 is the frozen `null_N2` logic with lo = L+6, hi = 2021 and the per-set spacing m (rejection sampling on sorted draws, as frozen), because the frozen function hard-codes 1912, 2021 and spacing 4.
6.6 Report for every set: n, S_lead, S_lag, null means, p_N1, p_N2, hit rate, list of markers with hit events and lead years. Events and markers are tabulated in full, not only summarised.

## 7. Support rule and falsification
**Supported (E1 primary only)** requires all of: S_lead/n ≥ 0.60 (raised from the draft's 0.50 on Kari's decision); S_lead > S_lag; p_N1 ≤ 0.05; p_N2 ≤ 0.05; and none of F4–F8 triggered.
**Falsified or not supported if any:**
- F1: S_lead/n < 0.60.
- F2: S_lead ≤ S_lag (drift is not earlier than after).
- F3: p_N1 > 0.05 or p_N2 > 0.05.
- F4: the C1 census control shows S_lead/n ≥ 0.50 with p_N1 ≤ 0.05. The result is voided as a calendar or method artefact. (Kept at 0.50 deliberately: a control should be easier to trip than the test.)
- F5 (hard failure): E1 passes F1–F3 under X^S but fails under X^A in the same direction, i.e. under X^A (its own P90, support from 1905, scored T in [1912, 2021]) S_lead ≤ S_lag or p_N1 > 0.05. Not supported. If E1 already fails F1–F3, F5 is reported but moot.
- F6: the N1 null-mean hit rate for E1 is ≥ 0.45. The test is declared uninformative, not supported, because chance alone nearly meets the threshold.
- F7 (anchoring check): let c_j be the number of scored E1 markers with an X^S upcrossing exactly j years before T (j = 0 is T itself; j = 1..5 the lead years). F7 triggers if c_0 ≥ 1 and c_0 ≥ max(c_1..c_5). Read as rater anchoring on the marker year; not supported.
- F8 (power floor): fewer than 5 X^S upcrossings. The test is declared uninformative.
(The 0.50 in F4 is the only place the draft's old threshold survives.) Failing the primary does not license promoting a secondary set. A secondary pass with a primary failure is reported as exploratory only.
